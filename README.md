## ✨ Features

- **Personalized Dashboard**: Track your daily progress and productivity metrics at a glance.
- **Task & Deadline Management**: Organize your life efficiently with intuitive task tracking.
- **Stunning UI/UX**: Built with modern web design principles featuring glassmorphism, dynamic gradients, and smooth micro-interactions.
- **Scroll-Driven Animations**: Engaging landing page with complex scroll animations powered by Framer Motion.
- **Responsive Design**: Flawless experience across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

### Frontend
- **Framework**: React + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion & Lottie-web
- **Deployment**: Vercel

### Backend
- **Database**: MongoDB
- **Server**: Express.js & Node.js

## 🚀 Quick Start

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ramanraj00/LockedIn.git
   cd LockedIn
   ```

2. **Setup Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Setup Backend:**
   *(Assuming there is a backend folder, run the respective install and start commands)*

## 🎨 Design Philosophy
LockedIn prioritizes visual excellence to create a "Comfort Space" for users. Instead of generic designs, it uses curated harmonious color palettes, modern typography, and scroll-orchestrated animations to make productivity feel less like a chore and more like an experience.
